Разрешить общение в публичном Telegram-чате после проверки обязательных подписок. GateKeeper проверяет членство в заданных каналах и чатах, ограничивает право писать и удаляет сообщения нарушителей.

Администратор настраивает список обязательных подписок, исключения и политику мутов. Участник запускает повторную проверку кнопкой в служебном сообщении группы. Уведомления дедуплицируются, чтобы повторные нарушения не превращались в поток одинаковых сообщений.

## Границы управления

Это MVP модерации одного сценария. Управлять ботом могут только пользователи из `ADMIN_USER_IDS`; статус администратора Telegram-чата сам по себе доступа не даёт. Боту нужны права в защищаемом чате и доступ к каналам, членство в которых он проверяет.

Временные муты снимает локальный воркер примерно через минуту после наступления срока. Команды настройки и требования к подключению приведены ниже.

Обсудить похожий проект: [sh3l.beer](https://sh3l.beer).

## Запуск

1. Создай `.env` на основе `.env.example`.
2. Установи зависимости: `python -m venv .venv && . .venv/bin/activate && pip install -e .`
3. Заполни `ADMIN_USER_IDS` списком `user_id`, которым разрешено управление ботом.
4. Запусти бота: `sub-bot`

## Команды

- `/help`
- `/setup`
- `/required_add [chat_id] [@username]`
- `/required_remove [chat_id|@username]`
- `/required_list`
- `/ttl [seconds]`
- `/cooldown [seconds]`
- `/mute_policy`
- `/whitelist_add [user_id]`
- `/whitelist_remove [user_id]`
- `/status`
- `/stats`

## Ограничения MVP

- Бот должен быть админом в защищаемом чате.
- Управление доступно только `user_id` из `ADMIN_USER_IDS`, а не всем админам Telegram-чата.
- Бот должен быть добавлен в обязательные каналы/чаты, чтобы проверять membership.
- Кнопки проверки работают прямо в групповом сервисном сообщении.
- Временный мут снимается локальным воркером бота примерно через 1 минуту.
